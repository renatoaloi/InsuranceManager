<task type="auto">
  <name>Task 1: Create Dockerfile for API container</name>
  <files>src/InsuranceManager.Api/Dockerfile</files>
  <action>
Create a multi-stage Dockerfile that:
1. Uses mcr.microsoft.com/dotnet/sdk:10.0 as build stage
2. Copies all project files (Api.csproj, Application.csproj, Infrastructure.csproj, Domain.csproj) for layer caching
3. Runs dotnet restore and dotnet build
4. Uses mcr.microsoft.com/dotnet/aspnet:10.0 as runtime stage
5. Creates non-root user "appuser" for security
6. Exposes port 8080 (ASPNETCORE_URLS controls this)
7. Adds HEALTHCHECK for /health endpoint
8. Sets working directory to /app and copies published output

Key configuration:
- ENV ASPNETCORE_URLS=http://+:8080
- ENV ASPNETCORE_ENVIRONMENT=Production
- HEALTHCHECK --interval=30s --timeout=3s --retries=3 CMD curl -f http://localhost:8080/health || exit 1
- USER appuser (after creating with adduser)
  </action>
