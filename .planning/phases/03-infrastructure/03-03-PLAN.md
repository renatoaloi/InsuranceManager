<tasks>

<task type="auto">
  <name>Task 1: Create docker-compose.yml</name>
  <files>docker-compose.yml</files>
  <action>
Create docker-compose.yml in project root with:

API Service (insurance-api):
- build: context=., dockerfile=src/InsuranceManager.Api/Dockerfile
- ports: "5000:8080" (host:container)
- environment:
  - ASPNETCORE_ENVIRONMENT=Production
  - ASPNETCORE_URLS=http://+:8080
  - API_KEY=${API_KEY} (from .env, NOT hardcoded)
  - ConnectionStrings__DefaultConnection=Data Source=insurance.db
  - Huey__QueuePath=/app/huey_data
  - Huey__PythonPath=python
- volumes: ./huey_data:/app/huey_data (bind mount for shared queue)
- depends_on: insurance-huey (worker starts after API)
- restart: unless-stopped

Huey Worker Service (insurance-huey):
- build: context=., dockerfile=Dockerfile.huey
- environment:
  - API_BASE_URL=http://api:8080 (Docker service name, not localhost)
  - INTERNAL_API_KEY=${INTERNAL_API_KEY:-internal-secret-change-me}
- volumes: ./huey_data:/app/huey_data (SAME volume as API)
- depends_on: insurance-api (worker starts after API)
- restart: unless-stopped

Volumes section:
- huey_data: driver=local (for named volume, or use bind mount)

Health checks should be included via HEALTHCHECK in Dockerfiles (not docker-compose healthcheck).
  </action>
  <verify>
<automated>

</automated>
  </verify>

</done>
