## Integration Findings

### Critical Gap: Adapter-Consumer Disconnect (GAP-1)

`QueueTaskRunnerAdapter.EnqueueStatusChangeAsync()` writes JSON files to `./huey_data/`, but `huey_consumer.py` processes those files through `process_json_queue_with_delay()`. The `@task()` decorated `process_status_change()` function is **never invoked** by the adapter's output. The two mechanisms run in parallel without connecting.

**E2E flow status:**
```
Step 1: API PATCH /proposals/{id}/status         ✅
Step 2: ProposalService.EnqueueStatusChangeAsync ✅ (writes JSON file)
Step 3: Huey consumer processes task              ⚠️ BROKEN (@task path dead)
Step 4: InternalController.UpdateStatus()        ✅
Step 5: DB update                                 ✅
```

### Warning: Python Huey Files in Application Layer (GAP-2)

`src/InsuranceManager.Application/Huey/` still contains `huey_config.py`, `huey_consumer.py`, `run_worker.py`. These are Python files (Infrastructure concern) copied to Application layer. `Dockerfile.huey:11` references `Application/Huey/`. This is inverted dependency: Infrastructure Python code lives in Application layer.
